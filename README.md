# CS Major Prep Guide

A multi-page website built for a Software Engineering course project, aimed at helping high school students learn what it's like to be a Computer Science major — covering career paths, salary info, how to prepare, and a "day in the life" walkthrough.

This was one of the first projects our team built together, serving as a starting point for the semester as we set up our workflow. It was a **group project** built by a team of four as part of CMSC 4123 (Software Engineering IV). We worked in feature branches off a shared `dev` branch, used pull requests to review each other's work, and set up GitHub Actions to auto-deploy to AWS on merge.

## Tech stack

- HTML / CSS / JavaScript
- Git & GitHub (feature branches, pull requests, code review)
- GitHub Actions (CI/CD deploy pipeline to an AWS EC2 instance via Apache)

## Pages

- Main landing page
- Careers in CS (jobs, salary info)
- Major prep guide
- "Day in the life" of a CS major (morning / afternoon / evening)
- More about studying CS

I was one of four contributors on this team, working across the codebase — including building out the Major Prep page, styling, and general team collaboration (reviewing pull requests, pairing on features, helping teammates debug). Full commit history is preserved in this repo.
